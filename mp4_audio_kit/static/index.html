    How it works
    • Files stay on this computer. Results expire after 30 minutes; cleanup checks run every minute. Clear list cancels pending work and retires saved results. Existing downloads finish before deletion.
    • Stop the app's terminal process to exit and remove results. Closing this browser tab leaves the server running.
    • The first audio track of each video becomes an MP3. Titles and other tags are not copied.
    • Two or more finished files can be saved together as one ZIP.
